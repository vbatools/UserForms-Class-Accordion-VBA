# Класс VBA Accordion

![Демонстрация проекта](Project_Image.gif)

Этот репозиторий содержит реализацию на VBA класса Accordion. Класс обеспечивает создание интерактивных аккордеонов с настраиваемым внешним видом и поведением.

## Возможности

- Создание многоуровневых аккордеонов
- Настройка внешнего вида заголовков и содержимого
- Поддержка анимации открытия/закрытия
- Возможность программного управления элементами
- Интеграция существующими формами
- Поддержка событий при открытии/закрытии элементов
- Гибкая система стилизации
- Управление видимостью элементов с помощью нового свойства Visible

## Установка

1. Скачайте файл `accordion_v3.xlsm`
2. Откройте его в Excel
3. В VBA редакторе импортируйте классы `clsAccordion.cls` и `clsAccordionItem.cls` в свой проект
4. При необходимости добавьте модуль `modShowForms.bas` и форму `frmTestClass.frm` для тестирования

## Быстрый старт

Для начала работы с классом аккордеона создайте экземпляр класса и настройте его параметры:

### Простой пример использования
```vba
Dim accordion As clsAccordion
Set accordion = New clsAccordion
accordion.SetParentForm Me ' Указываем родительскую форму
accordion.AddItem "Заголовок 1", "Содержимое первого элемента"
accordion.AddItem "Заголовок 2", "Содержимое второго элемента"
accordion.CreateControls ' Создаем элементы управления
```

## Основные функции

Класс `clsAccordion` предоставляет следующие основные функции:
- `AddItem` - добавление нового элемента аккордеона
- `RemoveItem` - удаление элемента аккордеона
- `ClearItems` - очистка всех элементов
- `ExpandAll` - развернуть все элементы
- `CollapseAll` - свернуть все элементы
- `SetStyle` - настройка стиля отображения
- `SetAnimation` - настройка параметров анимации

## Работа с элементами управления

Каждый элемент аккордеона представлен классом `clsAccordionItem`, который позволяет:
- Управлять видимостью элемента
- Изменять заголовок и содержимое
- Настройка внешнего вида
- Обработка событий открытия/закрытия

## Настройка стиля

Класс поддерживает настройку стилей через методы:
- `SetHeaderStyle` - стиль заголовков
- `SetContentStyle` - стиль содержимого
- `SetColors` - цветовая схема
- `SetFont` - настройка шрифта

## Устранение неполадок

Если вы столкнулись с проблемами при использовании класса, проверьте следующее:
- Убедитесь, что все зависимости импортированы правильно
- Проверьте, что родительская форма установлена с помощью `SetParentForm`
- Убедитесь, что элементы управления создаются после добавления всех элементов
